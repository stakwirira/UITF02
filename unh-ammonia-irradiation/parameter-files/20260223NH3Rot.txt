# Components: Nitrogen + Hydrogen
# Mass fractions for NH3 from stoichiometry
#   N atomic mass ≈ 14.007
#   H atomic mass ≈ 1.008  -> 3 * 1.008 = 3.024
#   Total mass ≈ 17.031
#   Mass frac N ≈ 14.007 / 17.031 = 0.822441
#   Mass frac H ≈ 3.024 / 17.031 = 0.177559
